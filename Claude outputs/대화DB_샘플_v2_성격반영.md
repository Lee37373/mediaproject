# 대화 데이터베이스 샘플 v2: 성격·가치관·특성 반영 (검토용)

v1에서는 말투만 달랐다면, v2는 같은 상황에서도 **그 사람이 누구냐에 따라 할 말 자체가 달라지게** 했습니다.

**한 사람의 대사가 정해지는 방식**

| 층 | 무엇으로 정해지나 | 무엇이 달라지나 |
|---|---|---|
| 말투 | MBTI + 특성 (게임 코드의 기존 규칙) | 문장 끝맺음, 길이 |
| 화제 | 가치관 (돈·명예·동료·모험·안전·지식) | 무슨 얘기를 꺼내는지, 무엇에 기뻐하고 화내는지 |
| 말버릇 | 특성 | 가끔 덧붙는 한 줄 |

말투 규칙: 거만 특성 → 거만한 반말 / 외톨이 특성 또는 내향(I)+사고형(T) → 무뚝뚝한 존댓말 / 사고형(T)+판단형(J) → 정중한 다나까 / 그 외 → 밝은 해요체. 내향형은 짧게, 외향형은 두세 문장.

---

## 1. 같은 잡담, 가치관만 다를 때

상황: 의뢰에서 돌아온 B에게 A(친근)가 말을 건다. B는 모두 무뚝뚝한 말투이고, 가치관만 다르다.

> A: 다녀왔어요? 이번 의뢰 어땠어요?

**B 가치관: 돈**
> B: 보수에 비해 품이 너무 들었어요.
> A: 그래도 받을 건 다 받았죠?
> B: …전리품 판 게 더 쏠쏠했어요.

**B 가치관: 명예**
> B: 우두머리는 제가 잡았어요.
> A: 오, 진짜요? 대단하다!
> B: …길드 기록에 이름 좀 올려 주세요.

**B 가치관: 동료**
> B: 다들 무사히 왔어요. 그거면 됐죠.
> A: 그쪽은요? 안 다쳤어요?
> B: 전 괜찮아요. 신참이 좀 놀랐을 뿐이에요.

**B 가치관: 모험**
> B: 또 똑같은 늑대 소굴이었어요.
> A: 지겨웠겠다.
> B: …다음엔 동쪽 폐광 같은 데 가 보고 싶네요.

**B 가치관: 안전**
> B: 생각보다 위험했어요. 지도엔 그런 말 없었는데.
> A: 다친 데는요?
> B: 없어요. 다음부턴 정찰부터 할 거예요.

**B 가치관: 지식**
> B: 거기 고블린들, 불을 무서워하던데요.
> A: 에이, 원래 그렇지 않아요?
> B: 아뇨. 이번 무리만 그랬어요. 적어 둬야겠어요.

## 2. 같은 위로, 위로하는 사람의 가치관이 다를 때

상황: 지친 B(정중)를 A(친근)가 위로한다. 위로하는 방식이 A의 가치관을 따른다.

> A: {B} 씨, 요즘 얼굴이 많이 안 좋아요.
> B: …괜찮습니다. 조금 피곤할 뿐입니다.

| A의 가치관 | A의 위로 | B의 대답 |
|---|---|---|
| 돈 | 피곤할 땐 잘 먹어야죠. 오늘 고기는 제가 낼게요. | …그럼 사양하지 않겠습니다. |
| 명예 | {B} 씨 없으면 우리 길드 안 돌아가요. 쓰러지면 안 돼요. | …그렇게까지 말씀하시니, 힘을 내 보겠습니다. |
| 동료 | 혼자 끙끙대지 말고 말해요. 우리 같은 편이잖아요. | …고맙습니다. 실은 요즘 잠을 잘 못 잡니다. |
| 모험 | 답답하면 바람이라도 쐬러 가요. 강가에 경치 좋은 데 있어요. | …그것도 나쁘지 않겠군요. |
| 안전 | 당분간 위험한 의뢰는 빼 달라고 해요. 몸이 먼저예요. | …그래도 되겠습니까? 말씀드려 보겠습니다. |
| 지식 | 왜 그런지부터 같이 따져 봐요. 원인을 알면 좀 나아요. | …생각해 보니, 지난 의뢰 이후부터인 것 같습니다. |

## 3. 같은 다툼, 서운한 이유가 가치관마다 다를 때

상황: A가 B에게 따진다. A가 무엇에 화났는지가 A의 가치관을 따른다.

| A의 가치관 | A | B |
|---|---|---|
| 돈 | 어제 전리품, 왜 네가 제일 많이 챙겼어? | 제일 많이 싸웠으니까. |
| 명예 | 우두머리는 내가 잡았는데 왜 보고는 네 이름으로 올라갔어? | 마무리는 내가 했잖아. |
| 동료 | 신참 다쳤을 때 왜 그냥 지나쳤어? | 그때 멈췄으면 다 같이 당했어. |
| 안전 | 또 혼자 돌격했지? 너 때문에 다 위험해진다고. | 기다렸으면 놓쳤어. |
| 모험 | 맨날 쉬운 의뢰만 고르니까 재미가 없잖아. | 쉬운 게 어때서. 살아 돌아오는 게 중요하지. |
| 지식 | 그 몬스터 불에 약하다고 내가 말했잖아. 왜 안 들어? | 책에서 본 거랑 실전은 달라. |

모험과 안전, 돈과 동료처럼 가치관이 부딪히는 짝은 다툼이 더 자주 나게 하면 자연스럽습니다.

## 4. 특성 말버릇

평소 대화 끝에 가끔 붙는 한 줄입니다. 아래는 해요체로 적었고, 실제 데이터에는 말투 4종 버전이 각각 들어갑니다.

| 특성 | 말버릇 |
|---|---|
| 용감 | 다음엔 더 센 놈 있는 데로 보내 주세요. |
| 튼튼 | 이 정도 상처쯤이야, 하룻밤 자면 나아요. |
| 명사수 | 그 거리에서 눈을 맞혔다니까요. 진짜예요. |
| 성실 | 내일은 몇 시에 출발해요? 미리 준비해 둘게요. |
| 빠른 학습 | 그 기술, 한 번만 더 보여 주세요. 금방 익힐게요. |
| 날렵 | 제가 먼저 가서 보고 올게요. 금방이에요. |
| 매의 눈 | 저기 풀숲, 아까부터 뭔가 움직여요. |
| 사교적 | 오늘 저녁 다 같이 먹을래요? 제가 자리 잡을게요! |
| 충직 | 길드가 가라면 가야죠. 어디든요. |
| 겁쟁이 | …거기 진짜 위험한 거 아니죠? |
| 허약 | 조금만 쉬었다 가도 될까요? 숨이 차서… |
| 덤벙 | 아, 또 물약 깨뜨렸다… 이번이 세 번째예요. |
| 게으름 | 오늘은 그냥 쉬면 안 돼요? |
| 욕심 | 그래서 제 몫은 얼마예요? |
| 느긋 | 천천히 가요. 몬스터가 어디 도망가나요. |
| 외톨이 | …전 혼자 갈게요. 그게 편해요. |
| 거만 | 그 정도는 나 혼자서도 충분해. |

## 5. 한 사람 따라가기

세 층이 합쳐지면 한 사람이 어느 상황에서든 같은 사람처럼 들립니다.

**카엘 · ENFP → 밝은 해요체 · 가치관: 모험 · 특성: 용감**

| 상황 | 대사 |
|---|---|
| 처음 만남 (영입) | 오, 여기가 그 길드예요? 요즘 북쪽에 이상한 게 나온다던데, 거기도 가요? |
| 의뢰 성공 | 생각보다 싱거웠어요! 다음엔 더 깊은 데로 가요! |
| 지쳤을 때 (면담) | 아… 요즘 좀 처지긴 했어요. 맨날 같은 데만 가서 그런가. |
| 다툼 | 맨날 쉬운 의뢰만 고르니까 재미가 없잖아요! |
| 말버릇 | 다음엔 더 센 놈 있는 데로 보내 주세요. |

**리안 · ISTJ → 무뚝뚝한 존댓말 · 가치관: 안전 · 특성: 겁쟁이**

| 상황 | 대사 |
|---|---|
| 처음 만남 (영입) | …여기 길드, 작년에 죽은 사람 있었어요? |
| 의뢰 성공 | 다친 사람 없죠. 그럼 됐어요. |
| 지쳤을 때 (면담) | …요즘 잠을 못 자요. 눈 감으면 그 동굴이 떠올라서. |
| 다툼 | 또 혼자 돌격했죠. 그러다 다 죽어요. |
| 말버릇 | …거기 진짜 위험한 거 아니죠? |

카엘과 리안을 같은 파티에 넣으면 가치관이 부딪혀 다툼이 나고, 화해하면 서로를 보완하는 이야기가 생깁니다.

---

**만드는 방식**
- 상황별 대사 틀은 말투 4종으로 만듭니다.
- 그중 화제 줄 하나만 가치관 6종으로 바꿔 끼웁니다.
- 말버릇은 특성 17종 × 말투 4종 = 68줄을 따로 두고 일정 확률로 덧붙입니다.
- 이렇게 나누면 전부 곱하지 않아도 되어, 전체 3천~4천 줄 안에서 사람마다 다르게 들립니다.
