## 알려진 문제
- **쉬운 의뢰에서도 사망이 나옵니다**: Lv1 궁수가 고블린 궁수에게 사망 → P3-6 중상 시스템(Q2 확정)으로 완화 예정
- **멸종이 너무 쉽습니다**: 둥지가 2개인 종(고블린)이 의뢰 한 번에 멸종한 사례가 있습니다 → P5-1(둥지 수 보장이 급하면 P3 중에 처리).
- **레벨업이 느립니다**: 게임 시간 1.5일 동안 모두 Lv.1이었습니다 → P5-1.
- **F3(안개 끄기)을 누르면 모든 둥지가 한꺼번에 "발견"됩니다**: `FogOfWar.Disabled`이면 `IsExplored`가 항상 true라서 `Nest`가 발견 이벤트를 냅니다. 디버그 전용이라 영향은 작습니다.
- **마을 대기 중인 모험가는 마을에 들어온 몬스터에게 반격하지 않습니다**: `TownIdleState`가 `HandleCombat`을 호출하지 않습니다 → P3-6 DefendState에서 처리.
- **LLM이 한 번 실패하면 에디터를 재시작해야 합니다**: 네이티브 에러 상태가 남습니다. 자세한 내용은 CLAUDE.md를 봅니다.
