## 3. 이번 세션에서 한 일 (09-20 ~ 09-21)

### 3-1. 영입 대화 이중 표시 수정
- 영입·설득 대화 문장이 **영입 창**에만 나와야 하는데 화면 왼쪽 아래 피드에도 같이 뜨던 것을 고쳤습니다.
- 방법: `Say(text, toFeed:false)`와 `AdventurerSpeechEvent.NoFeed`. 말풍선은 그대로 뜹니다.

### 3-2. LLM 모델 교체와 프롬프트 경량화
- **원인**: 씬의 모델이 Qwen3-14B(9.0GB)인데 개발 PC의 GPU(RTX 5070 Laptop, VRAM 8GB)에 다 안 올라가 답이 40초 넘게 걸리거나 시간 초과가 나고, 규칙 기반 대체 대사만 나와서 대화 품질이 낮았습니다. 플레이 종료·컴파일 때 Unity가 수 분씩 멈추는 부작용도 있었습니다.
- **비교**(같은 PC, 인게임 측정): Qwen3-14B 40초+, Qwen3.5-4B 약 1.8초(한국어 문장 붕괴), **Gemma 3 4B 약 2.0~2.3초(자연스러움)**.
- **채택**: `gemma-3-4b-it-Q4_K_M.gguf`. 영입 4턴 테스트에서 4번 모두 LLM 응답이 성공하고 영입 성공 판정까지 정상이었습니다.
- **에디터 메뉴** `GuildMaster > LLM`(`Scripts/Editor/LlmModelSwap.cs`): Gemma 3 4B / Qwen 3.5 9B / Qwen3-4B Instruct 2507로 바꾸기, 현재 모델 확인. 플레이 중에는 실행되지 않습니다.
- **프롬프트 경량화**: 영입 시스템 프롬프트에서 시설·최근 소식·호감도를 줄이거나 뒤로 옮기고, 응답은 60자 안팎(최대 100자), `MaxTokens` 400→220, 시간 제한 40→25초, 온도 0.8→0.6. 설득 프롬프트도 같은 한도입니다.
- **규칙 기반 대체 대사 개선**: 인사·자기소개 질문에 맞는 답, 짧은 말에 벌점 없음, 중립 대사 풀 확대. 영입 창 상태줄에 "생각 중… (N초)"와 대체 사유(시간 초과 등)를 표시합니다.

### 3-4. F-6 죽음·부상의 결과
영구 사망은 유지하고, 죽음 전후의 선택지를 붙였습니다.

| 기능 | 요약 |
| --- | --- |
| 추모의 벽(`H`) | 쓰러진 길드원 최근 30명. 추모식·유품 회수·현장 보기 |
| 유품 | 죽은 자리에 떨어진 장비·전리품을 추적. 현장에 있음 / 되찾음 / 잃음. 48게임시간 뒤 썩음 |
| 유품 회수 파견 | 친했던 길드원 우선 한 명이 홀로 갔다 옴. 체력 70% 이상·마을에서 쉬는 중이어야 함 |
| 추모식 | 골드 `40 + 10×레벨`. 죽은 이를 좋아했던 길드원의 스트레스가 내림 |
| 구사일생 | 치명타를 맞을 때 확률(25%+레벨·가치관 보정, 최대 50%)로 체력 1로 생존. 3초 무적, 후퇴, 스트레스 +20 |
| 중상 | 구사일생 뒤 12게임시간 의뢰 거절(자동·LLM·설득이 같은 규칙) |

수치는 전부 `LegacyRules`에, 문구는 `LegacyTexts`에 있습니다.

### 3-5. 죽음·추모의 스트레스를 호감도 기준으로 변경 (요청 반영)
- 요청: "호감도가 높으면 더 받고 낮으면 덜 받음, 0 미만이면 스트레스 면제".
- **동료 사망 스트레스**(`StressRules.DeathStress`): 호감도 0 미만이면 0, 0이면 +5, 50 이상이면 +25로 선형. 호감도는 −100~100인 방향 값(내가 그를 어떻게 보나)입니다. 이전의 고정값(`AllyDiedStress`, `FriendDiedExtra`)은 삭제했습니다.
- **추모식 완화**(`LegacyRules.MemorialRelief`): 죽던 순간의 호감도로 0이면 −4, 50 이상이면 −16. 0 미만이거나 죽은 뒤에 들어온 길드원은 변화도 기억도 없습니다.
- `FallenRecord.Relations`에 죽는 순간 남은 길드원들의 호감도를 기록해 추모식에서 씁니다.

### 3-6. F-6 플레이 검증 (2차)
디버그 메뉴로 사망·시계·호감도를 만들고 로그 파일로 값을 읽어 확인했습니다.

| 확인한 것 | 결과 |
| --- | --- |
| 호감도별 죽음의 스트레스 | −30 → 변화 없음, 60 → +25, 0~1 → +5~5.4 |
| 호감도별 추모식 | 60 → −16(54.3→38.3), −30 → 변화·기억 없음, 문구의 인원이 맞음 |
| 친구의 유품 파견 | 친구가 감. 되찾은 뒤 기억 2개("유품을 되찾아 왔다", "마음이 조금 놓였다") |
| 회수자 없음 | 버튼 비활성, 이유가 마우스 올리면 뜸 |
| 파견 중 후퇴 | 체력을 30%로 깎자 회수를 접고 귀환, 유품은 현장에 남음 |
| 유품 소실 | 시계 +49시간 → "시간이 지나 사라졌습니다"(×2). 고블린 전사가 가져간 경우도 확인 |
| 실전 구사일생 | 고블린 전사 4마리에게서 "구사일생" 알림·체력 1·후퇴 중·중상 (확률만 고정) |
| 중상 의뢰 거절 | 체력이 찬 같은 길드원이 중상인 동안은 안 받고, 풀린 직후 LLM 결정으로 수락·완료 |
| 기록 30건 한도 | 31건째부터 가장 오래된 기록이 밀림 |

**아직 못 본 것**: 죽은 뒤에 들어온 길드원의 추모식 제외와 호감도 중간값(단위 테스트만), 파견의 8시간 시간 초과, 설득 대화 쪽의 중상 거절, 마을 안에서 죽었을 때 몬스터가 유품을 가져가는 경우.

**알게 된 것**
- 구사일생은 "한 번 더 도망칠 기회"입니다. 고블린 전사 4마리가 바짝 붙어 있으면 무적 3초가 끝난 뒤(실시간 약 3초) 쓰러졌습니다. 너무 가혹하면 `LegacyRules.GraceSeconds`나 후퇴 속도를 먼저 조정하세요.
- 마을 밖에서 쓰러지면 유품을 몬스터가 몇 게임시간 안에 가져갈 수 있어, 파견은 죽자마자 보내야 합니다.
- 되찾은 장비는 기존 전리품 규칙대로 길드에 팔립니다(후임에게 물려주는 기능이 아닙니다).
- 추모식·치료 비용은 정산 보고서에 전용 항목이 없어 "기타 지출"로 잡힙니다.
- 쓰러진 길드원 기록은 저장되지 않습니다(프로젝트에 저장 기능이 아직 없음).

## 6. 개발·검증 도구와 단축키

**단축키** (2026-09-23 실제 바인딩에 맞춰 정정, P4-61): `Q` 의뢰 게시판, `R` 길드원, `I` 창고, `E` 생태계, `T` 행상인, **`B` 건설**, **`L` 정산**, `N` 알림, `H` 추모의 벽. 그 밖에 `Space`(일시정지), **`1~4` 속도(x1·x2·x4·x8)**, `M` 미니맵, **`F5` 이름표**, `F2~F6`(시험·디버그용), `` ` ``(단축키 도움말), `ESC`. 창을 열어 둔 동안은 게임이 멈춥니다.

> 이 문서에 `B 정산`으로 적혀 있었으나 코드에서는 `B`가 건설이고 정산은 `L`입니다. 이름표 토글도 `N`이라 알림 창과 겹쳐서, 알림 창을 열 때마다 이름표가 꺼졌습니다. 이름표를 `F5`로 옮겼습니다.

**에디터 메뉴**
- `GuildMaster > LLM`: 모델 교체·확인(`LlmModelSwap.cs`).
- `GuildMaster > Legacy`: 길드원 0번 사망 / 마을 밖 사망 / 치명타(구사일생 확정) / 기록 보기 (`LegacyDebugMenu.cs`).
- `GuildMaster > Legacy > 검증`: 호감도 설정, 스트레스 로그, 추모식 전후 비교, 시계 +49시간, 슬라임 소환, 실전 전투, 가짜 기록 채우기, HP 30%·최대 등. 플레이 중에만 눌립니다.
- 이 메뉴가 남기는 `[Legacy]` 로그는 프로젝트 루트의 `legacy_verify.log`에도 복사됩니다. **지워도 되는 파일**입니다.

**작업 방식 메모**
- Unity는 창에 포커스가 올 때만 컴파일됩니다(Ctrl+R로 강제). 컴파일 후 `error CS`를 확인합니다.
- 플레이 중에 에디터 스크립트를 고치면 플레이를 끄고 다시 컴파일해야 메뉴가 갱신됩니다.
- `Assets/**`의 `.cs`는 CRLF(BOM 없음), `.md`는 LF입니다.
